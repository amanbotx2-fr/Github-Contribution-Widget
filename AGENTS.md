# AGENTS.md

Project: Github Contribution Widget

Build a native macOS SwiftUI + WidgetKit app.

Goal:
Minimal glassmorphism GitHub contribution widget for macOS desktop.

Rules:
- Work autonomously.
- Do not ask approval for normal file edits, creation, formatting, build commands, or fixes.
- Ask only before destructive actions.
- Start with mock data first.
- Use SwiftUI and WidgetKit.
- Keep UI minimal: username, active dot, total contributions, current streak, longest streak, contribution heatmap, less/more legend.
- No top repositories.
- No percentage comparison.
- No extra bottom graph.
- Commit after each major milestone.
